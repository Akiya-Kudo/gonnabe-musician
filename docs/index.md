このナレッジベースは、**「外出先での3分が、次に楽器を持つ時間につながる音楽練習アプリ」**を検討・開発するための共有資料です。構想、設計、アイデア、調査、検証結果、意思決定を `docs/` に集約し、継続的に更新します。

## 現在の位置づけ

ユーザーから提供された初期提案を整理した段階です。需要、演奏への効果、継続、支払い意欲は未検証で、対象楽器、名称、技術構成、価格、期間、費用は提案または計画上の仮定です。サービスの実装完了や事業性の確認を意味しません。

初期提案は、Web開発経験のある個人がAIを活用して初期版を開発することを現実的と評価しています。ただし、教材監修、実機検証、利用者観察、運営の時間を確保することが前提です。

## この方針の核

1. 楽器のない時間に、耳・リズム・読譜・音楽の理解・演奏のイメージ・練習の振り返りに取り組む。
2. 自分の演奏でのつまずきから課題を選び、移動中に練習し、次に楽器で確かめる。
3. スマホ上の成績と実際の演奏力を分け、演奏へのつながりを検証する。
4. 最初は1楽器、正解の明確な課題、監修済みの短い教材で小さく試す。
5. 忙しい生活の中で戻りやすい、穏やかな練習体験をつくる。

構想から新たに加えた設計案は、その旨を明記します。原文との対応は[出典資料](./research/references.md)から確認できます。
