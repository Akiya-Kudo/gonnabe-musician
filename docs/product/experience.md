## 学習の流れ

**学ぶ → 試す → 気づく → 後日思い出す → 楽器で確かめる。** 毎回「何が少しできるようになったか」が分かる体験にします。解説を読む時間と、思い出して試す時間の両方を設けます。

## 機能案と優先度

以下は原文の提案であり、実装済み機能の一覧ではありません。

| 機能案 | 体験の例 | 優先度 |
| --- | --- | --- |
| 今日の3分練習 | 使える時間と苦手に応じて、取り組む課題を一つ提示 | 初期版 |
| リズムの再現 | 2小節を聴いてタップ。ずれた部分をゆっくり再挑戦 | 初期版 |
| 音と譜面の対応 | 聴いた旋律に合う譜面を選ぶ、譜面から音を予想する | 初期版 |
| 苦手の復習 | 間違えた内容を、音や調を変えて後日出題 | 初期版 |
| 次に弾くためのメモ | 「週末はこの2小節を、ゆっくり弾く」と残す | 初期版 |
| 練習の振り返り | 「止まった」「リズムが不安」などを選ぶと関連課題へつながる | 初期版 |
| 和音・曲の構造の練習 | コードを組み立て、響きやフレーズの区切りを確かめる | 追加 |
| 自分の曲との連携 | 練習している曲の課題から、外出用の練習を作る | 検証後 |
| 録音へのフィードバック | 音程・タイミングを確認し、次の課題を提案 | 検証後 |

## 3分体験の例：付点のリズムで止まる人

1. 短いフレーズを聴く。
2. 合うリズムを選び、タップして再現する。
3. 難しかった部分だけ、音を分けて練習する。
4. 最後に別のフレーズで試す。
5. 次に楽器で確かめる箇所を一つ持ち帰る。

課題での成功を演奏力の証明に置き換えず、次に楽器で確かめる行動につなげます。

## 利用状況に合わせたモード

| 利用状況 | できること |
| --- | --- |
| イヤホンあり | 聴き分け、リズム、旋律の練習 |
| 音を出せない | 読譜、鍵盤や指板の位置、コードの組み立て |
| 楽器あり | 外出中に取り組んだ課題を短く演奏して確認 |

通勤中の使いやすさを中核機能として扱います。片手で操作でき、30秒でも区切れ、中断した続きにすぐ戻れることを重視します。
