## 提供価値の仮説

**外出先での3分が、次に楽器を持つ時間につながる音楽練習アプリ。** 日常の学習と実際の演奏を結びつけることを、事業の核として提案します。

耳、リズム、読譜、音楽の理解、演奏のイメージ、練習の振り返りは、楽器がない時間にも取り組めます。忙しくても音楽に触れ、次の演奏で取り組むことを一つ持ち帰れる体験を目指します。

これは初期の方向性です。需要や演奏への効果は、利用者との検証が必要です。

## 伸ばしたい能力と演奏との接続

| 能力 | 楽器なしでできる練習 | 実際の演奏とのつながり |
| --- | --- | --- |
| リズム | 聴いて再現、拍の穴埋め、音が消えても拍を維持 | 譜面のリズムを理解し、テンポを保つ準備 |
| 耳 | 音の上下、旋律、和音の違い、間違いの聴き分け | 弾き間違いへの気づき、耳コピーの基礎 |
| 読譜 | 音符・休符・拍子を読み、音や位置と対応させる | 演奏前の譜読みを進める |
| 音楽の理解 | コードの構成、繰り返し、フレーズの区切りを探す | 曲を覚え、演奏の見通しを持つ |
| 演奏のイメージ | 譜面を見て頭の中で音を再生する | 暗譜や演奏前の準備を補助 |
| 練習の振り返り | つまずいた箇所を記録し、関連課題を復習する | 次の練習で取り組むことが明確になる |

## 価値の範囲と限界

押弦の力加減、鍵盤のタッチ、息の使い方などは実物での確認が必要です。スマホ上の操作成績と楽器の演奏力を分けて扱います。

楽器を使わないイメージ練習には、熟練ピアニストの演奏改善を示した[研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3747442/)が原文で紹介されています。ただし、同研究では実際に弾く練習の改善がより大きく、初心者に同じ効果を保証するものではありません。本サービス自体の有効性が確認されたわけではありません。

## 競合と差別化の仮説

原文では、既存サービスの例として次が挙げられています。提供内容は原文の記載であり、継続的な競合調査は今後の課題です。

| サービス | 原文で紹介された機能 |
| --- | --- |
| [Duolingo](https://blog.duolingo.com/music-course/) | 画面上の鍵盤を使った読譜・リズム・音の学習 |
| [EarMaster](https://www.earmaster.com/products/ear-training-sight-singing/earmaster-for-mobile.html) | 聴音、リズムタップ、成績に応じた出題 |
| [Tomplay](https://tomplay.com/how-it-works) | 楽譜と音源の連動、テンポ変更、部分反復 |

「スマホで音楽を学べる」だけでは十分な差別化になりません。今回検証したいのは、**自分の演奏上のつまずき → 移動中の練習 → 次回の演奏確認**がつながる価値です。

初期版では、「リズム」「譜読み」などのつまずきを利用者が選ぶだけでこの流れをつくります。曲の自動解析は、この価値を確認してから追加できます。
